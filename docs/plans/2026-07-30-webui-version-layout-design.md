# WebUI 版本信息双列布局设计

## 目标

将 WebUI 工作台“版本与更新”中的信息展示对齐首页版本信息格式，并把组合文案拆成两个独立条目：版本、配置状态。

## 布局

- 信息区采用单行双列，版本在左，配置状态在右，两列等宽。
- 两个条目继续使用首页的“图标 + 标题 + 值”视觉格式。
- 更新按钮保留在整行最右侧，不改变现有更新流程和可用状态。
- 不增加嵌套卡片或新的配置入口。

## 数据与状态

- 版本值继续读取 WORKBENCH_VERSION，无法读取或未安装时显示 —。
- 配置状态沿用现有状态机映射：未安装、待安装依赖、已安装配置、运行中。
- 深浅主题继续通过 theme_manager token 更新，不添加硬编码主题色。

## 验证

- UI 单元测试确认两个条目位于同一行、不同列且列宽权重一致。
- UI 单元测试确认版本值与配置状态值分别更新。
- 运行 WebUI 页面主题、缓存及完整 WebUI 单元测试。
